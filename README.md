# MoziHub - Movie Streaming App Prototype

MoziHub is a mobile-responsive movie streaming web application built with React, Vite, and Tailwind CSS.

## Features
- **TMDB API Integration:** Live fetch for trending movies, top rated, and live search.
- **Fallback Stream Player:** Embedded HTML5 video playback for sample videos.
- **Local Persistence:** Watchlist and subscription settings saved directly in localStorage.
- **Vercel Ready:** Built using Vite for seamless deployment on Vercel.

## Quick Start (Local Setup)

1. Extract the ZIP archive.
2. Open terminal in the directory and run:
   ```bash
   npm install
   ```
3. Start local development server:
   ```bash
   npm run dev
   ```

## Deploying to Vercel

1. Push this project folder to GitHub, GitLab, or Bitbucket.
2. Go to [Vercel](https://vercel.com) and click **Add New Project**.
3. Import your repository and click **Deploy**. Vercel will automatically detect Vite settings!
